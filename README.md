# rotorooter-pwa

Independent design study of the Roto-Rooter® marketing site. Not affiliated with Roto-Rooter or its franchisees.

- Motionsites seed: `datacore-booking-hero`
- Craft bar: SERVPRO liquid glass — semi-opaque frost nav + cards, 5px radii, dense phone-first IA
- Exact public marketing copy and brand red `#C8102E` / navy `#1B2A4A`
- Official homepage meta + Open Graph
- Installable PWA (manifest + service worker)
- Mock schedule → Submit Payment flow
- Hero parallax pauses for reduced-motion, hidden tabs, and offscreen heroes
